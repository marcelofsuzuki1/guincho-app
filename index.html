Link para clientes

O cliente abre o link, marca onde está o veículo e o destino, vê uma estimativa com os seus preços e manda o pedido para o WhatsApp da empresa. O pedido chega com um link que abre a viagem já preenchida aqui.

O link leva os preços e a base salvos. Se mudar algum deles, gere e divulgue o link de novo.

Backup / troca com o PC

Exporte para mandar as viagens ao programa do PC (WhatsApp, Drive, e-mail). Importe um arquivo exportado pelo PC para trazer as viagens de lá. Viagens repetidas não são duplicadas.

Distâncias: OpenStreetMap (Nominatim + OSRM). As viagens ficam só neste celular.
